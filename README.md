# Doom - My Microcontroller Shenanigans
This repository contains the programs for each of my small microcontroller playgrounds, `Doom_Stick` and `Doom_Grid`!

You might notice that none of the desciptions are very specific... That's because these are *playgrounds*, not long-lasting, persistent projects. The code they're running can completely change within a day.

## Why "`Doom`"?
One very simple reason: it's funny to call something completely and utterly harmless the Stick Of Doom! And because I suck at naming things interesting names

## Details

* `Doom_Stick` is a stock Raspberry Pi Pico W, running either MicroPython or CircuitPython (depending on what mood I'm in and what I'm doing). 

* `Doom_Grid` is a hacked Kano Pixel Kit, now running MicroPython against its will. Took a few flashes, but I got a hold of it eventually!
